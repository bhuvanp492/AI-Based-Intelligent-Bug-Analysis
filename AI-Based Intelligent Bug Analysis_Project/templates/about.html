Engineering Pipeline Architecture Modular Design

AI-Based Intelligent Bug Analysis and Security Risk Prioritization System is designed to relieve developer cognitive burden during bug report triage by executing automated multi-dimensional analysis:

  1. Data Engineering: Ingestion of CSV feeds with flexible column aliases, encoding detection (UTF-8, UTF-8-BOM, Latin-1), duplicate fingerprinting (SHA-256), and safe text cleaning preserving technical tokens.
  2. AI Engineering: TF-IDF n-gram feature extraction fit strictly on training splits to prevent data leakage. Multi-target Multinomial Naive Bayes probabilistic classifiers predict Severity, Bug Category, and Affected Module.
  3. Security Engineering: Hybrid vulnerability identification combining ML classification with 9 rule-based CWE regex signature engines and contextual evidence snippet extraction.
  4. Prioritization: Deterministic 0-100 risk scoring algorithm incorporating impact factors, prediction uncertainty, and module criticality.
  5. Triage & Governance: SQLite ACID storage, human-in-the-loop review workflow, TF-IDF cosine similarity clustering, and audit logging.

Academic Notice: Synthetic demonstration datasets are used for initial calibration. The system functions as an automated prioritization aid and strictly does not declare suspected vulnerabilities as confirmed exploits without verification.

Documented 0–100 Risk Prioritization Formula Deterministic Model

The system assigns a composite risk score on a 0 to 100 integer scale:

Risk Score = Min(100, BaseSeverity + MLSecurityScore + RuleIndicatorsScore + ModuleCriticality)
1. Base Severity Weight (Max 40 pts): Critical = 40 pts, High = 25 pts, Medium = 15 pts, Low = 5 pts.
2. ML Security Classification Factor (Max 25 pts): If predicted category is Security Issue, score = Round(Probability × 25); else 0 pts.
3. Rule-Based Security Indicators (Max 25 pts): Sum of weights from detected CWE indicator rules, clamped to 25 pts max.
4. Affected Module Impact Factor (Max 10 pts): Payment, Authentication, Database = 10 pts; API, Registration = 5 pts; Dashboard, UI, Other = 0 pts.
Risk Prioritization Levels:
0 - 25: Low Risk 26 - 55: Medium Risk 56 - 80: High Risk 81 - 100: Critical Risk
